# Clayface workspace

Mode: Operate. Authority: Clayface.md Visual System v1 and the confirmed fixture-shell milestone.

Build directly in code for this session. No standing workflow preference is inferred or stored.

Task: open a sample project, inspect a direction, select a page section, edit supported content and variants, compare directions, adjust project tokens, preview and return without losing browser-local work.

World: a restrained design workbench. Warm neutral chrome, Geist typography, a restrained clay accent, crisp borders, compact semantic controls. Brand appears in the small geometric mark and careful type. Generated content has its own palette.

Geometry: 48px top bar, 224px navigation, 288px inspector, remaining width for the canvas. Below 1100px the inspector opens on demand; below 760px navigation becomes a drawer and preview adapts.

First viewport: populated Forma homepage in the canvas; page hierarchy at left; content and variant controls at right; the active direction and browser save state always visible.

Quality contract: working controls, no invented live integrations, no trapped scrolling, complete empty/error/limit/delete states, keyboard access, token-driven chrome, shared renderer for editor and preview.
